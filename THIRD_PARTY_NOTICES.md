# Third-party components

Nexora OS is built on open-source software and open-weight models. Public distributions must preserve the licenses/notices of included components.

Major components include Debian GNU/Linux, the Linux kernel, KWin/Wayland, Qt, systemd, PipeWire/WirePlumber, NetworkManager, Flatpak, llama.cpp, Qwen model weights, whisper.cpp, and eSpeak NG. Each remains governed by its own upstream license.

Before a commercial production release, generate a complete machine-readable dependency/license manifest from the exact ISO build and review redistribution obligations, especially LGPL/GPL components and model/voice assets.
